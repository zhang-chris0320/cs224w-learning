# CS224W Learning

本仓库用于 Stanford CS224W（Machine Learning with Graphs）自学，记录课程学习笔记、代码实验、作业过程和个人研究想法。

## 官方资源

- 官方课程主页：[https://web.stanford.edu/class/cs224w/](https://web.stanford.edu/class/cs224w/)
- 官方 notes：[https://github.com/snap-stanford/cs224w-notes](https://github.com/snap-stanford/cs224w-notes)

本仓库不直接复制 Stanford 官方 `cs224w-notes`，仅保留上面的官方仓库链接。

## 推荐学习顺序

`Lecture → Slides → Notes → Colab → Personal Notes → Research Ideas`

作业与完整解答不要公开传播。本仓库保持 **Private**，仅用于个人学习和研究整理。

## 目录说明

- `notes/`：个人课程笔记
- `colabs/`：课程 Colab 实验记录
- `homework/`：作业过程与个人实现
- `code/`：NetworkX、PyTorch 和 PyG 代码实验
- `papers/`：论文阅读记录
- `experiments/`：课程外实验
- `project/transformer-as-node/`：将 Transformer / LLM 与图学习联系起来的研究想法

# Transformer-as-Node

这是一个待探索的研究方向，而不是已经验证的结论。

## 初始研究想法

- 可以尝试将完整的 Transformer / LLM 模型视为 graph node。
- 节点属性可能包括 architecture、hidden representation、task performance 和 confidence。
- 边可能来自 output similarity、representation similarity、disagreement、knowledge overlap 或 teacher-student relation。
- 后续可以探索 node embedding、message passing、heterogeneous graph、graph transformer 和 multi-model reasoning。

这些内容目前仅代表研究假设和问题清单，后续需要通过文献阅读、定义设计和实验进行检验，不能视为已验证的结论。
